What does Tilebrush do?

Tilebrush is a pixel art and sprite animation editor for iPad and iPhone. Draw with Apple Pencil or your finger, use layers and an animation timeline, and export PNG, GIF, APNG, sprite sheets with JSON and .aseprite files. Unlimited artworks, layers and PNG export are free; one optional one-time purchase (Pro) adds animation and game export tools. There is no subscription, account or advertising.

Drawing

  • Tools: pencil (with pixel-perfect lines), eraser, fill (connected area or every matching pixel), line, rectangle, ellipse (outline or filled), selection, move, color picker. The slider button next to the tools sets brush size and shape.
  • Symmetry: left–right, top–bottom or both mirrors, from the top bar.
  • Apple Pencil and fingers: until you use Apple Pencil, one finger draws and two fingers move the canvas. After a Pencil touch, only the Pencil draws and one finger moves the canvas (change it in Settings › Draw with finger). Pinch to zoom, two-finger tap to undo, three-finger tap to redo. A double tap on Apple Pencil (2nd generation or Pro) switches between pencil and eraser.
  • Keyboard (iPad): B pencil, E eraser, G fill, L line, U rectangle, O ellipse, M select, V move, I color picker, X swap colors, [ ] brush size, , and . previous/next frame, Return play, ⌘Z undo, ⇧⌘Z redo, ⌘A select all, ⌘D deselect, ⌘0 zoom to fit.
  • Colors: tap a palette color to draw with it; long-press to edit or remove it. The palette menu loads built-in palettes, imports and exports .gpl and .hex files (order is kept exactly). In indexed artworks, changing a palette color changes every pixel that uses it.

Layers and animation

  • Add, duplicate, merge, delete, hide, lock and rename layers; set layer opacity.
  • The timeline shows every frame. Tap a frame to edit it, use onion skin to see the previous and next frame, and press play. Tags name parts of an animation (forward, reverse, ping-pong).

Saving, versions and Recently Deleted

  • Tilebrush saves while you draw and right away when you leave the app. Files are written so that an interrupted save never replaces your art with a broken file.
  • Version History (editor ⋯ menu, or long-press an artwork): a version is kept each time you open an artwork and every 10 minutes of drawing, up to 30. Restoring keeps the current state as a version too.
  • Recently Deleted (trash button in the gallery) keeps deleted artworks for 30 days; restore them or delete them for good there.
  • Artworks are stored on this device only. Deleting the app deletes them, so use Export › Tilebrush project file (or long-press › Share Project File) to keep copies elsewhere.

Files

  • Open: the gallery's Import button opens .aseprite / .ase, PNG and Tilebrush project files as new artworks (the original file is not changed). Layer groups are flattened in order and tilemap layers are left out; Tilebrush tells you when that happens.
  • Export: PNG of the current frame at 1–16× and the project file are free. Animated GIF, APNG, sprite sheets (horizontal, vertical or grid, padding, with JSON frame data and tags) and .aseprite files need Pro. GIF has 1-bit transparency and at most 256 colors.

Free and Pro

  • Free: unlimited artworks and layers, all drawing tools, symmetry, onion skin, PNG export, project backups, opening .aseprite files, version history and Recently Deleted. Animations you already have stay viewable and editable frame by frame.
  • Pro (one-time, non-consumable in-app purchase): add, duplicate and reorder frames, frame durations and tags, GIF / APNG / sprite sheet export, .aseprite saving and tile mode (draw across the edges of a seamless tile and see it repeat).
  • Restore: on the purchase screen or in Settings › Restore Purchases, signed in with the same Apple Account. Refunds are handled by Apple at reportaproblem.apple.com.

Good to know

  • iPad and iPhone, iOS/iPadOS 17 or later. English, Japanese, Brazilian Portuguese, Spanish, French, German, Italian, Korean and Simplified Chinese.
  • "Aseprite" names a compatible file format; Tilebrush is not affiliated with it.

한국어

Tilebrush는 iPad와 iPhone용 픽셀 아트·스프라이트 애니메이션 편집기입니다. Apple Pencil이나 손가락으로 그리고, 레이어와 애니메이션 타임라인을 쓰고, PNG·GIF·APNG·JSON이 있는 스프라이트 시트·.aseprite 파일로 내보냅니다. 작품·레이어·PNG 내보내기는 무제한 무료이며, 선택형 한 번 구매(Pro)로 애니메이션과 게임용 내보내기 도구가 열립니다. 구독·계정·광고는 없습니다.

  • 도구: 연필(픽셀 퍼펙트 선), 지우개, 채우기(연결된 영역/같은 색 전체), 직선·사각형·타원, 선택, 이동, 스포이트, 대칭(좌우·상하·상하좌우). 도구 옆 슬라이더 버튼에서 브러시 크기와 모양을 고릅니다.
  • Apple Pencil과 손가락: Pencil을 쓰기 전에는 손가락 하나로 그리고 두 손가락으로 캔버스를 움직입니다. Pencil로 한 번 그리면 Pencil로만 그리고 손가락 하나로 캔버스를 움직입니다(설정 › 손가락으로 그리기). 핀치로 확대, 두 손가락 탭은 실행 취소, 세 손가락 탭은 다시 실행입니다.
  • 저장: 그리는 동안, 그리고 앱을 떠나는 즉시 저장합니다. 저장이 중간에 끊겨도 깨진 파일이 작품을 덮어쓰지 않도록 씁니다. 작품을 열 때마다·10분 그릴 때마다 버전을 남기고(최대 30개), 삭제한 작품은 ‘최근 삭제된 항목’에 30일 동안 보관합니다. 작품은 이 기기에만 저장되므로 앱을 지우기 전에 프로젝트 파일을 공유해 사본을 두세요.
  • 파일: 갤러리의 가져오기로 .aseprite/.ase, PNG, Tilebrush 프로젝트 파일을 새 작품으로 엽니다(원본은 바뀌지 않음). 레이어 그룹은 순서대로 풀고 타일맵 레이어는 제외합니다. 현재 프레임 PNG(1–16배)와 프로젝트 파일 내보내기는 무료입니다.
  • 무료: 작품·레이어 무제한, 모든 그리기 도구, 대칭, 어니언 스킨, PNG 내보내기, 프로젝트 백업, .aseprite 열기, 버전 기록, 최근 삭제된 항목. 이미 있는 애니메이션은 프레임별로 계속 보고 고칠 수 있습니다.
  • Pro(한 번 구매, 비소모성): 프레임 추가·복제·순서 변경, 프레임 시간과 태그, GIF·APNG·스프라이트 시트 내보내기, .aseprite 저장, 타일 모드. 복원은 구매 화면이나 설정 › ‘구매 복원’. 환불은 Apple(reportaproblem.apple.com)에서 처리합니다.
  • iOS/iPadOS 17 이상. 영어, 일본어, 브라질 포르투갈어, 스페인어, 프랑스어, 독일어, 이탈리아어, 한국어, 중국어 간체. ‘Aseprite’는 호환 파일 형식의 이름이며 Tilebrush와 관계가 없습니다.
