ENGLISH SUPPORT

Working with Brieflume

Where should I start?

In an empty library, choose Explore the sample to try three original geometric studies without using personal photos. If you already have projects, use Library options → Add sample project. Or create a project, add a reference, and record its title, source, observation and use decision. Images are optional. Select two to four cards with their circle controls, then choose Compare.

What stays free?

Create, open and edit reference projects; add selected images, sources and notes; search and compare; preview and export the basic PDF; and export or import an editable project. You can also open existing or imported saved briefs and export their PDFs without Pro. Deleting your own content does not require a purchase.

What does Pro add?

Pro adds saving and editing named brief configurations: a card selection, its order, sections, introduction and PDF content options. Preview a configuration and its PDF before buying. A saved brief uses the current cards in its project; it is not a frozen copy of the images or notes.

Pro is an optional one-time, nonconsumable purchase, with no subscription. It does not increase storage limits. The price will come from the App Store when the product is available; there is no confirmed public price on this page.

PDF or editable backup?

Project options → Export reference brief (PDF) prepares pages you can inspect before saving. Choose whether to include observations and sources. The basic PDF can include all cards or only ideas marked Use this.

Export editable project saves a complete .brieflume copy containing every card, source, observation, image and saved brief. Import that file from Projects to create a separate project; it does not replace an existing one. A PDF is not an editable project backup.

What happens if I delete something?

Deleting a reference removes its local card and image, not the original in Photos or Files. A saved brief that used it will mark the missing reference. Deleting a saved brief removes that configuration, not the source cards. Project deletion and app deletion can remove local work; keep an editable backup first. There is no in-app trash or automatic backup service.

How do I restore Pro?

Use the Apple Account that bought Pro, connect to the internet, then open About → Brieflume Pro → Restore purchases. Apple may ask you to authenticate. Restore checks Pro access; it does not recover project files or transfer them from another device.

If purchase information is unavailable, use Reload purchase information. A pending or unverified transaction does not unlock Pro. Purchase status never deletes your projects or saved briefs. For payment or refund requests, visit Apple purchase support.

What are the working limits?

Up to 30 projects and 60 references per project. JPEG, PNG and HEIC/HEIF images: up to 15 MiB each, 60 MiB combined per project, 64 megapixels and 20,000 pixels on either edge. An editable project file can be up to 90 MiB. Each project can hold 12 saved briefs, each with up to 12 sections and 60 selected references. These limits apply to free and Pro use. One MiB is 1,048,576 bytes.

Unsupported, damaged or oversized imports are rejected. If saving fails, check the message and available storage; keep the original file and do not delete the app as a first troubleshooting step.

Is everything offline and private?

Editing locally available projects, comparison and PDF generation run on the device. There is no Brieflume account, developer server, advertising or analytics SDK. Apple purchases, cloud files and photos that need downloading can require internet access. Brieflume does not automatically fetch source websites or sync projects between devices.

The app retains image bytes received from your chosen Photos or Files provider, which may convert the original format. Those bytes can include location or other metadata. An editable backup includes the whole project, even when a PDF omits notes or sources. Review the file and its destination before sharing. Recording a source does not grant permission to reuse its content.

Contact support

Email ppupy1200@gmail.com with the app version, iOS/iPadOS version, device model and steps to reproduce the problem. Describe the error before sending a project file. Only attach content you are comfortable sharing; remove personal information where possible. Do not send passwords, verification codes or payment card details.

Brieflume 도움말

어디서 시작하나요?

보관함이 비어 있을 때 예시 프로젝트 둘러보기를 선택하면 개인 사진 없이 자체 제작한 세 가지 기하학 예시를 살펴볼 수 있습니다. 프로젝트가 이미 있다면 보관함 옵션 → 예시 프로젝트 추가를 사용하세요. 직접 프로젝트를 만들고 레퍼런스를 추가해 제목·출처·관찰 메모·활용 결정을 기록해도 됩니다. 이미지는 선택 사항입니다. 카드의 원형 선택 버튼으로 2~4개를 고른 뒤 비교를 누르세요.

무엇이 무료인가요?

프로젝트 만들기·열기·편집, 선택한 이미지와 출처·메모 추가, 검색·비교, 기본 PDF 미리보기·내보내기, 편집 가능한 프로젝트 내보내기·가져오기는 무료입니다. 기존 또는 가져온 브리프 구성 열기와 해당 PDF 내보내기도 Pro 없이 가능합니다. 본인의 자료 삭제에도 구매가 필요하지 않습니다.

Pro는 무엇을 추가하나요?

Pro로 이름 있는 브리프 구성을 저장하고 편집할 수 있습니다. 카드 선택·순서, 섹션, 도입문과 PDF 포함 옵션을 다시 사용하세요. 구매 전에 구성과 실제 PDF를 미리 볼 수 있습니다. 저장한 브리프는 프로젝트의 현재 카드를 사용하므로 이미지나 메모를 고정 보관하는 사본은 아닙니다.

Pro는 선택형 비소모성 일회성 구매이며 구독이 아닙니다. 저장 용량 제한은 늘어나지 않습니다. 상품이 제공되면 App Store에서 불러온 가격을 표시하며, 이 페이지에 확정된 판매 가격은 없습니다.

PDF와 백업은 어떻게 다른가요?

프로젝트 옵션 → 레퍼런스 브리프 내보내기 (PDF)에서 저장할 페이지를 먼저 확인하세요. 관찰 메모와 출처의 포함 여부를 선택할 수 있습니다. 기본 PDF는 모든 카드 또는 활용하기로 정한 아이디어만 포함할 수 있습니다.

편집 가능한 프로젝트 내보내기는 모든 카드·출처·관찰 메모·이미지·저장한 브리프가 담긴 .brieflume 사본을 저장합니다. 프로젝트에서 해당 파일을 가져오면 기존 자료를 교체하지 않고 별도 프로젝트가 만들어집니다. PDF는 편집 가능한 프로젝트 백업이 아닙니다.

삭제하면 어떻게 되나요?

레퍼런스를 삭제하면 앱 안의 카드와 이미지가 제거되며 사진·파일 앱의 원본은 바뀌지 않습니다. 해당 카드를 사용한 브리프에는 삭제된 레퍼런스가 표시됩니다. 저장한 브리프를 삭제해도 원본 카드는 남습니다. 프로젝트나 앱을 삭제하면 로컬 작업이 사라질 수 있으니 먼저 편집 가능한 백업을 보관하세요. 앱 안의 휴지통이나 자동 백업 서비스는 없습니다.

Pro 구매는 어떻게 복원하나요?

Pro를 구매한 Apple 계정으로 인터넷에 연결한 뒤 안내 → Brieflume Pro → 구매 복원을 누르세요. Apple 인증이 필요할 수 있습니다. 복원은 Pro 이용 권한을 확인하며 프로젝트 파일을 복구하거나 다른 기기에서 가져오지 않습니다.

상품 정보가 보이지 않으면 구매 정보 다시 불러오기를 사용하세요. 대기 중이거나 검증되지 않은 거래로 Pro를 해제하지 않습니다. 구매 상태 때문에 프로젝트나 저장한 브리프가 삭제되지는 않습니다. 결제·환불 문의는 Apple 구매 지원에서 확인할 수 있습니다.

사용 범위는 어떻게 되나요?

프로젝트 최대 30개, 프로젝트마다 레퍼런스 최대 60개입니다. JPEG·PNG·HEIC/HEIF 이미지는 각각 15MiB, 프로젝트 합계 60MiB, 6,400만 화소 및 가로·세로 각각 20,000픽셀 이내입니다. 편집 가능한 프로젝트 파일은 최대 90MiB입니다. 프로젝트당 저장한 브리프 12개, 브리프당 섹션 12개와 선택한 레퍼런스 60개까지 지원합니다. 무료와 Pro에 동일하게 적용됩니다. 1MiB는 1,048,576바이트입니다.

지원하지 않거나 손상된 파일, 제한을 넘긴 파일은 가져오지 않습니다. 저장에 실패하면 안내 메시지와 기기 여유 공간을 확인하세요. 원본 파일을 보관하고 문제 해결을 위해 앱부터 삭제하지 마세요.

오프라인 사용과 개인정보는요?

기기에 있는 프로젝트의 편집·비교·PDF 생성은 기기 안에서 처리합니다. Brieflume 계정, 개발자 서버, 광고나 분석 SDK는 없습니다. Apple 구매, 클라우드 파일과 아직 내려받지 않은 사진에는 인터넷이 필요할 수 있습니다. 출처 웹사이트를 자동 수집하거나 프로젝트를 기기 간 자동 동기화하지 않습니다.

선택한 사진·파일 제공자가 전달한 이미지 데이터를 보관하며, 제공자가 원본 형식을 변환할 수 있습니다. 데이터에는 위치 정보 등의 메타데이터가 남아 있을 수 있습니다. PDF에서 메모나 출처를 빼더라도 편집 가능한 백업에는 전체 프로젝트가 포함됩니다. 공유 전에 내용과 저장 대상을 확인하세요. 출처 기록만으로 콘텐츠 사용 권한을 얻는 것은 아닙니다.
